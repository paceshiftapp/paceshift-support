## Publishing

This repository is a static GitHub Pages site with no build step.

1. Put the files at the repository root.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select the `main` branch and `/(root)`.
4. Save, then verify every public URL in a signed-out browser window.

The site uses static HTML and CSS. It contains no developer-added analytics, advertising, cookies, contact form, remote fonts, or JavaScript.
